Kompakte WPF/MVVM-Vorlage für die Prüfung. Die Kapitel folgen der Reihenfolge, in der man arbeitet:
*Lesen → Logik → DB/Import → ViewModel → Fenster/Dialoge → XAML → Custom Draw → Tests*.
Alle Snippets verwenden neutrale Platzhalter-Namen (Tabelle unten) und sind zum Kopieren und Anpassen gedacht.

== Ablauf in der Prüfung

[cols="1,5"]
|===
| *0. Lesen* (10 min)
| Angabe + Tests lesen. Alle Namen notieren, die Tests aufrufen (Properties, Methoden, Commands, Konstruktor).
  `TODO`/`NotImplementedException` suchen. Einmal bauen. Welche Vorlage? → <<vorlage>>
| *1. Logik*
| Helper/Parser ohne UI (Extension, Regex, Try-Muster). Helper-Tests laufen lassen, bis grün. → <<logik>>
| *2. DB + Import*
| Entities + DbContext-Mapping, Migration (`Add-Migration`, `Update-Database`), Repository-Abfrage (Filter + `Select` in DTO), `ImportService` (Transaktion, Navigation-Properties, ein `AddAsync`),
  Konsolen-Import. → <<db>>
| *3. ViewModel*
| Pro Feld eine Property mit `SetProperty`, Listen als `ObservableCollection`. Pro Button `CanXxx()` + `Xxx()` + `XxxCommand`.
  Laden in `InitializeDataAsync` bzw. `Load()`. → <<vm>>
| *4. Dialoge*
| Fenster + ViewModel in DI registrieren, Dialog-Methode in `IWindowNavigator` + `WindowNavigator`. → <<fenster>>
| *5. XAML*
| Bild in waagrechte Bereiche zerlegen → `Grid` mit `Auto` (fest) und `+*+` (wächst mit). Binden, Styles. → <<xaml>>
| *6. Custom Draw*
| `UserControl` mit `DependencyProperty` + `OnRender`, Bounding Box skalieren. → <<draw>>
| *7. Testen*
| Alle Tests grün, ggf. eigenen Test schreiben. App durchklicken: falsche Eingabe (Button grau?),
  Fenster größer ziehen, zweimal laden (keine Doppelten). → <<tests>>
|===

*Häufige Punkteverluste:* Code im Code-Behind · ganze Tabelle laden statt in der DB filtern · Button nicht korrekt
aktiv/inaktiv · Liste nach erneutem Laden doppelt (`Clear()` fehlt) · Eingabefelder nach dem Hinzufügen nicht geleert ·
beim Vergrößern wächst der falsche Bereich.

=== Platzhalter-Namen

Per Suchen/Ersetzen (ganzes Wort, Groß-/Kleinschreibung beachten) an die Angabe anpassen:

[cols="1,4",options="header"]
|===
| Platzhalter | Bedeutung
| `Item` | Haupt-Entity: wird importiert, in der Übersicht gelistet, im Detail-Dialog angezeigt
| `Category` | Nachschlage-Entity mit nullable Fremdschlüssel `Item.CategoryId` (Filter-ComboBox, bearbeitbar)
| `Detail` | 1:n-Kind von `Item` mit laufender Nummer `SeqNo` (z. B. Zeilen/Werte/Schritte aus der Datei)
| `Tag` | m:n-Beziehung zu `Item`, in der Liste als Text „A,B“ angezeigt
| `Entry` / `EntryRow` | Datensatz einer Datei (DTO) / Zeile in der Tabelle (UI)
| `Document` | UI-Model mit Kopfdaten + Liste von `EntryRow` (Datei-Vorlage)
|===

== Projekt und Vorlage

=== Vorlage A: Datei (Base.WpfMvvm / Logic / WPFApp / UnitTest)

----
MyTest.sln
├── Base.WpfMvvm/  ← Lehrer: NotifyPropertyChanged, RelayCommand(Param), BaseViewModel, Navigator
├── Logic/         ← DTOs + Manager (Datei laden/speichern) + Helpers (Extension-Methoden)
├── WPFApp/        ← Models/ (UI-Models), ViewModels/, Views/, Datendatei
└── UnitTest/      ← xUnit + FluentAssertions, testet das ViewModel
----

* Tests legen die Namen fest. Was der Test aufruft, muss `public` sein und genau so heißen.
* ViewModel braucht einen parameterlosen Konstruktor (`new MainViewModel()` im Test). Kein Laden/MessageBox im Konstruktor.
* Base-Klassen nicht neu schreiben, sondern erben: `class Document : NotifyPropertyChanged`.
* `RelayCommand` = ohne Parameter (`new RelayCommand(Save, CanSave)`), `RelayCommandParam` = mit `CommandParameter`.

=== Vorlage B: Datenbank (Core / Persistence / Wpf.ViewModels / Wpf)

----
MyApp.sln
├── Base/             ← Lehrer: AppService (DI), GenericRepository, BaseUnitOfWork, Transaction
├── Base.WpfMvvm/     ← Lehrer: NotifyPropertyChanged, RelayCommand, BaseViewModel, Navigator
├── Core/             ← Entities, Contracts (IUnitOfWork, I...Repository), DTOs, Parser
├── Persistence/      ← ApplicationDbContext, UnitOfWork, ...Repository, ImportService
├── ImportConsoleApp/ ← Konsolen-Import (Ordner → DB)
├── Wpf.ViewModels/   ← ViewModels + IWindowNavigator (kennt keine Fenster)
└── Wpf/              ← App.xaml(.cs), Views/, Controls/, WindowNavigator
----

* Reihenfolge: Entities lesen bzw. anlegen → DbContext + Migration → Repository-Abfrage → ImportService → ViewModel → View.
* ViewModels in eigenem Projekt → im XAML mit Assembly einbinden:
  `xmlns:vm="clr-namespace:Wpf.ViewModels;assembly=Wpf.ViewModels"`.

[source,csharp]
----
public class NotifyPropertyChanged : INotifyPropertyChanged    // Basis für Models + ViewModels
{
    public event PropertyChangedEventHandler? PropertyChanged;

    protected void OnPropertyChanged([CallerMemberName] string? name = null)
        => PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(name));

    protected bool SetProperty<T>(ref T field, T value, [CallerMemberName] string? name = null)
    {
        if (EqualityComparer<T>.Default.Equals(field, value)) return false;
        field = value;
        OnPropertyChanged(name);
        return true;
    }
}

public class RelayCommand : ICommand
{
    private readonly Action<object?>     _execute;
    private readonly Predicate<object?>? _canExecute;

    public RelayCommand(Action<object?> execute, Predicate<object?>? canExecute = null)
    {
        _execute    = execute;
        _canExecute = canExecute;
    }

    public RelayCommand(Action execute, Func<bool>? canExecute = null)       // ohne Parameter
        : this(_ => execute(), canExecute == null ? null : _ => canExecute()) { }

    public bool CanExecute(object? parameter) => _canExecute == null || _canExecute(parameter);
    public void Execute(object? parameter)    => _execute(parameter);

    public event EventHandler? CanExecuteChanged      // WICHTIG: sonst Button immer aktiv/grau
    {
        add    => CommandManager.RequerySuggested += value;
        remove => CommandManager.RequerySuggested -= value;
    }
}
----

* `CanExecute` wird nach jeder Eingabe automatisch neu geprüft. Ändert sich der Zustand ohne Eingabe
  (Timer, nach `await`): `CommandManager.InvalidateRequerySuggested();`.
* `_canExecute == null` prüfen, *nicht* `_canExecute() == null` (ruft auf → `NullReferenceException`).

== Logik und Helper (ohne UI)

=== Extension-Methode, Try-Muster, Regex

[source,csharp]
----
public static class ValueExtensions                 // static class + static Methode + "this"
{
    // Format "12:34" bzw. "1:02:34" (Gruppe 1 optional) - Regex an die Angabe anpassen
    private static readonly Regex TimeRegex = new(@"^\s*(?:(\d+):)?(\d{1,2}):(\d{2})\s*$");

    public static bool TryParseTime(this string? s, out int seconds)   // Logik nur hier
    {
        seconds = 0;                                 // out in jedem Pfad setzen
        if (string.IsNullOrWhiteSpace(s)) return false;
        var m = TimeRegex.Match(s);
        if (!m.Success) return false;
        int h   = m.Groups[1].Success ? int.Parse(m.Groups[1].Value) : 0;   // optionale Gruppe
        int min = int.Parse(m.Groups[2].Value);
        int sec = int.Parse(m.Groups[3].Value);
        if (min > 59 || sec > 59) return false;      // Bereiche prüfen
        seconds = h * 3600 + min * 60 + sec;
        return true;
    }

    public static bool IsValidTime(this string? s) => s.TryParseTime(out _);

    public static int ToSeconds(this string s)       // werfende Variante
        => s.TryParseTime(out var r) ? r : throw new FormatException($"Ungültig: '{s}'");

    public static string ToTimeText(this int seconds)   // 3725 → "1:02:05", 2525 → "42:05"
    {
        if (seconds < 0) throw new ArgumentOutOfRangeException(nameof(seconds));
        int h = seconds / 3600, m = seconds % 3600 / 60, s = seconds % 60;
        return h > 0 ? $"{h}:{m:00}:{s:00}" : $"{m}:{s:00}";
    }

    public static (int part, int rest) DivRem(this int value, int size)    // Tupel zurückgeben
        => (value / size, value % size);
}

bool ok = "42:05".IsValidTime();                   // Aufruf wie Instanzmethode (using ...Helpers;)
var (part, rest) = 125.DivRem(60);                 // Tupel zerlegen: 2, 5
----

* Regex: `^ $` Anfang/Ende · `\d` Ziffer · `+` 1-n · `*` 0-n · `?` optional · `( )` Gruppe · `(?: )` ohne Auslesen ·
  `[A-Z]{2}` zwei Großbuchstaben · `@"..."` verbatim. Nur prüfen: `Regex.IsMatch(s, @"^[A-Z]{2}\d{3}$")`.
* Ausnahmen: `ArgumentOutOfRangeException(nameof(x))`, `FormatException`, `ArgumentNullException`.
* Format: `{m:00}` zweistellig, `{x:0.00}` / `{x:F2}` zwei Nachkommastellen, `{x:0.##}` höchstens zwei.
* Extension auf Tupel: `public static string ToText(this (int a, int b) t)` → Aufruf `(1, 5).ToText()`.
* Zahl sicher parsen: `double.TryParse(text, NumberStyles.Float, CultureInfo.InvariantCulture, out var d)`
  (Punkt als Dezimaltrenner, `1,5` wird abgelehnt).

=== Text zeichenweise parsen (Zahl als Prefix + Befehlszeichen)

[source,csharp]
----
// Beispiel "3A2b5$C": Zahl vor einem Zeichen = Wiederholung bzw. Wert, Zeichen = Befehl
public static List<Detail> Parse(string text)       // Core/Parser.cs: public static class Parser
{
    var result = new List<Detail>();
    int prefix = 0, option = 0;
    foreach (char c in text)
    {
        if (char.IsAsciiDigit(c))                    // mehrstellige Zahl aufbauen
        {
            prefix = prefix * 10 + (c - '0');
            continue;
        }

        int count = prefix == 0 ? 1 : prefix;        // fehlt die Zahl → 1
        if (c == '$')
            option = prefix;                         // Sonderzeichen: Zahl als Wert merken
        else if (c is >= 'A' and <= 'Z')
            result.Add(new Detail { Code = c - 'A', Count = count, Option = option });
        else if (c is >= 'a' and <= 'z')
            result.Add(new Detail { Code = c - 'a', Count = count, Option = null });
        else
            continue;                                // unbekannt (Leerzeichen, \n): ignorieren
        prefix = 0;                                  // nach jedem Befehl zurücksetzen
    }
    return result;
}
----

* `c - 'A'` macht aus einem Buchstaben eine Zahl (`'A'` → 0, `'B'` → 1), `c - '0'` aus einer Ziffer.
* `c is >= 'A' and <= 'H'` prüft einen Bereich. Groß-/Kleinbuchstabe als Variante (z. B. mit/ohne Option).

=== Text in Werte zerlegen (Kommentar, Trennzeichen, n*wert)

[source,csharp]
----
// "# Kopf\n4.2 3*3.1 x; -0.5"  →  4.2, 3.1, 3.1, 3.1, null, -0.5
var values = new List<double?>();
foreach (var raw in content.Split('\n'))
{
    int hash = raw.IndexOf('#');
    var line = hash >= 0 ? raw[..hash] : raw;                    // Kommentar abschneiden
    var separators = new[] { ' ', '\t', '\r', ';' };
    foreach (var token in line.Split(separators, StringSplitOptions.RemoveEmptyEntries))
    {
        int count = 1;
        var text  = token;
        int star  = token.IndexOf('*');
        if (star >= 0)                                           // "3*12.5"
        {
            if (!int.TryParse(token[..star], out count) || count < 1) continue;
            text = token[(star + 1)..];
        }
        double? value;
        if (text is "x" or "X") value = null;                    // Platzhalter für "fehlt"
        else if (double.TryParse(text, NumberStyles.Float, CultureInfo.InvariantCulture, out var d))
            value = d;
        else continue;                                           // ungültig → ignorieren
        for (int i = 0; i < count; i++) values.Add(value);
    }
}
----

* `s[..n]` = Zeichen 0 bis n-1, `s[(n + 1)..]` = alles nach Position n. `RemoveEmptyEntries` gegen doppelte Trenner.

=== CSV-/Textdatei lesen und schreiben

[source,csharp]
----
// Datei:  Titel;10.5        ← Kopfzeile
//         3;Text;2391       ← Datenzeilen
var lines   = File.ReadAllLines(fileName);
var header  = lines.First().Split(';');
var entries = lines.Skip(1)
    .Where(l => !string.IsNullOrWhiteSpace(l))            // leere Zeilen ignorieren
    .Select(l => l.Split(';', 3))                          // max. 3 Teile, ';' im Text bleibt
    .Select(c => new Entry { Number = int.Parse(c[0]), Text = c[1], Value = int.Parse(c[2]) })
    .OrderBy(e => e.Number).ThenBy(e => e.Text)
    .ToList();
double km = double.Parse(header[1], CultureInfo.InvariantCulture);

var output = new List<string> { $"{title};{km.ToString(CultureInfo.InvariantCulture)}" };
output.AddRange(entries.Select(e => $"{e.Number};{e.Text};{e.Value}"));
File.WriteAllLines(fileName, output);                     // überschreibt; AppendAllLines hängt an

string tags = string.Join(",", item.Tags.Select(t => t.Name));   // Liste als Text "A,B"
----

* Dezimalzahlen in Dateien immer mit `InvariantCulture` lesen *und* schreiben.

== Datenbank und Import

=== Entities anlegen (Core/Entities)

[source,csharp]
----
public class Item : EntityObject                       // Vorlage: EntityObject = Id + RowVersion
{
    [MaxLength(100)] public string  Name        { get; set; } = "";   // string  = NOT NULL
    [MaxLength(256)] public string? Description { get; set; }         // string? = NULL erlaubt
    public DateOnly CreationDate { get; set; }
    public decimal  Price        { get; set; }

    public int?      CategoryId { get; set; }            // int? = optionaler Fremdschlüssel
    public Category? Category   { get; set; }            // Navigation (n-Seite von 1:n)

    public List<Detail> Details { get; set; } = new();   // 1:n (Kinder)
    public List<Tag>    Tags    { get; set; } = new();   // m:n (Gegenseite: List<Item>)
}

public class Category : EntityObject
{
    [MaxLength(50)] public string Name  { get; set; } = "";
    public List<Item>             Items { get; set; } = new();
}

public class Detail : EntityObject                     // 1:n-Kind
{
    public int   ItemId { get; set; }                  // int = Pflicht → Cascade Delete
    public Item? Item   { get; set; }
    public int     SeqNo  { get; set; }
    public int     Code   { get; set; }
    public int     Count  { get; set; }
    public int?    Option { get; set; }
    public double? Value  { get; set; }
}

public class Tag : EntityObject                        // m:n ohne Zusatzdaten
{
    [MaxLength(50)] public string Name  { get; set; } = "";
    public List<Item>             Items { get; set; } = new();
}

public class Rating : EntityObject                     // m:n MIT Zusatzdaten = eigene Entity
{
    public int  ItemId { get; set; }
    public Item? Item  { get; set; }
    public int  TagId  { get; set; }
    public Tag?  Tag   { get; set; }
    [Range(1, 5)] public int Stars { get; set; }
    public DateTime Created { get; set; }
}
----

* Konventionen: Property `Id` = Primärschlüssel (Identity). `XxxId` + Navigation `Xxx` = Fremdschlüssel.
  `int?` = optional (beim Löschen `SetNull`), `int` = Pflicht (Cascade). Zwei `List<>`-Seiten = m:n mit Join-Tabelle.
* Ohne Vorlage selbst: `public int Id { get; set; }` und für Concurrency `[Timestamp] public byte[]? RowVersion { get; set; }`.
* Attribute: `[Required]`, `[MaxLength(n)]`, `[Range]`, `[NotMapped]` (keine Spalte), `[ForeignKey(nameof(X))]`,
  `[Column(TypeName = "decimal(10,2)")]`, an der Klasse `[Index(nameof(Name), IsUnique = true)]`. `enum` wird als `int` gespeichert.

=== DbContext und Mapping (Persistence)

[source,csharp]
----
public class ApplicationDbContext : DbContext
{
    public DbSet<Item>     Items      => Set<Item>();   // ein DbSet pro Tabelle
    public DbSet<Category> Categories => Set<Category>();
    public DbSet<Detail>   Details    => Set<Detail>();
    public DbSet<Tag>      Tags       => Set<Tag>();
    public DbSet<Rating>   Ratings    => Set<Rating>();

    public ApplicationDbContext() { }                   // für Migrationen / ohne DI
    public ApplicationDbContext(DbContextOptions<ApplicationDbContext> options)
        : base(options) { }

    protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
    {
        if (optionsBuilder.IsConfigured) return;        // DI hat schon konfiguriert
        var cs = ConfigurationHelper.GetConfiguration().GetConnectionString("DefaultConnection");
        optionsBuilder.UseSqlServer(cs);
    }

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        modelBuilder.Entity<Item>(e =>
        {
            e.HasIndex(i => i.Name).IsUnique();         // eindeutig
            e.Property(i => i.Name).HasMaxLength(100).IsRequired();
            e.Property(i => i.Price).HasPrecision(10, 2);   // decimal immer festlegen
            e.HasOne(i => i.Category)                   // 1:n explizit
             .WithMany(c => c.Items)
             .HasForeignKey(i => i.CategoryId)
             .OnDelete(DeleteBehavior.SetNull);
            e.HasMany(i => i.Tags).WithMany(t => t.Items);  // m:n, Join-Tabelle automatisch
        });

        modelBuilder.Entity<Detail>()
            .HasIndex(d => new { d.ItemId, d.SeqNo }).IsUnique();   // zusammengesetzt eindeutig

        modelBuilder.Entity<Rating>()
            .HasOne(r => r.Item).WithMany().HasForeignKey(r => r.ItemId)
            .OnDelete(DeleteBehavior.Restrict);         // mehrere Cascade-Pfade vermeiden

        modelBuilder.Entity<Category>().HasData(        // Startdaten (Id fix angeben!)
            new Category { Id = 1, Name = "Default" });
    }
}
----

[source,json]
----
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=(localdb)\\MSSQLLocalDB;Database=MyAppDb;Trusted_Connection=True"
  }
}
----

* `appsettings.json` liegt im Startprojekt, Eigenschaften: *In Ausgabeverzeichnis kopieren = Immer kopieren*.
* Zertifikatsfehler beim Verbinden → `;TrustServerCertificate=True` an den Connection-String anhängen.
* Konvention reicht meistens. `OnModelCreating` nur für: Unique-Index, `decimal`-Genauigkeit, Delete-Verhalten,
  zusammengesetzte Schlüssel (`e.HasKey(x => new { x.AId, x.BId })`), Startdaten.
* „multiple cascade paths“ beim `Update-Database` → bei einer Beziehung `OnDelete(DeleteBehavior.Restrict)` setzen.
* NuGet: `Microsoft.EntityFrameworkCore.SqlServer` (Persistence), `Microsoft.EntityFrameworkCore.Tools`
  (für `Add-Migration`), `Microsoft.EntityFrameworkCore.Design` (Startprojekt).

=== Migration erstellen (Visual Studio)

. Startprojekt festlegen: Rechtsklick auf das Projekt mit `appsettings.json` und Referenz auf Persistence
  (z. B. `ImportConsoleApp` oder `Wpf`) → *Als Startprojekt festlegen*.
. *Ansicht → Weitere Fenster → Paket-Manager-Konsole*. Oben *Standardprojekt* = `Persistence` (wo der DbContext liegt).
. Befehle eingeben:

[source,powershell]
----
Add-Migration InitialCreate          # erzeugt Persistence/Migrations/..._InitialCreate.cs
Update-Database                      # wendet alle offenen Migrationen auf die DB an

Add-Migration AddPrice               # nach jeder Modelländerung: neue Migration + Update-Database
Remove-Migration                     # letzte, noch NICHT angewendete Migration löschen
Update-Database InitialCreate        # auf einen älteren Stand zurück (0 = alles zurück)
Drop-Database                        # DB löschen (danach Update-Database = frisch)
Get-Migration                        # Liste, welche angewendet sind

# Projekte explizit angeben, wenn das Dropdown nicht passt
Add-Migration InitialCreate -Project Persistence -StartupProject ImportConsoleApp
----

[source,sh]
----
# Alternative im Terminal (einmalig: dotnet tool install --global dotnet-ef)
dotnet ef migrations add InitialCreate --project Persistence --startup-project ImportConsoleApp
dotnet ef database update            --project Persistence --startup-project ImportConsoleApp
----

[source,csharp]
----
// DB beim Import frisch aufbauen (Konsole, vor dem Import; Vorlage hat evtl. eigene UoW-Methoden)
await using var context = new ApplicationDbContext();
await context.Database.EnsureDeletedAsync();      // alte DB weg
await context.Database.MigrateAsync();            // alle Migrationen anwenden
----

* „The term 'Add-Migration' is not recognized“ → Paket `Microsoft.EntityFrameworkCore.Tools` fehlt.
* „Unable to create an object of type 'ApplicationDbContext'“ → parameterloser Konstruktor + `OnConfiguring` fehlt,
  falsches Startprojekt, oder `appsettings.json` wird nicht ins Ausgabeverzeichnis kopiert.
* „Build failed“ → erst die ganze Projektmappe fehlerfrei bauen; die Migration baut das Startprojekt.

public async Task<List<ItemDto>> GetOverviewAsync(int? categoryId)
{
    IQueryable<Item> query = DbSet.AsNoTracking();          // bzw. _context.Items
    if (categoryId != null)
        query = query.Where(i => i.CategoryId == categoryId);   // Filter läuft als SQL

    return await query
        .OrderBy(i => i.CreationDate)
        .Select(i => new ItemDto
        {
            Id           = i.Id,
            Name         = i.Name,
            CreationDate = i.CreationDate,
            CategoryId   = i.CategoryId,
            Category     = i.Category != null ? i.Category.Name : null,
            DetailCount  = i.Details!.Count,                // COUNT, lädt keine Details
            Tags         = string.Join(",", i.Tags!.OrderBy(t => t.Name).Select(t => t.Name)),
            MinValue     = i.Details!.Where(d => d.Value != null).Min(d => d.Value),
        })

* DTOs werden nicht getrackt → zum Ändern die Entity per Id neu laden.

[cols="3,2"]
|===
| `await _uow.ItemRepository.GetNoTrackingAsync(filter, orderBy, includes)` | Liste nur lesen

| `CountAsync(filter)` / `ExistsAsync(id)` | Anzahl / existiert?
| `await AddAsync(entity)` / `Remove(entity)` | neu / löschen (erst mit SaveChanges in der DB)
| `await _uow.SaveChangesAsync()` | speichern

=== ImportService (eine Transaktion pro Datensatz)

[source,csharp]
----
public class ImportService : IImportService              // Persistence; in DI registrieren
{
    private readonly IUnitOfWork _uow;
    public ImportService(IUnitOfWork uow) => _uow = uow;

    public async Task ImportItemAsync(string name, string? description, string? category,
                                      DateOnly date, string fileName)
    {
        var details = Parser.Parse(await File.ReadAllTextAsync(fileName));  // eigener Parser

        using var trans = _uow.BeginTransaction();

        if (await _uow.ItemRepository.CountAsync(i => i.Name == name) > 0)
            throw new InvalidOperationException($"'{name}' existiert bereits.");

        for (int i = 0; i < details.Count; i++)
            details[i].SeqNo = i + 1;                    // laufende Nummer ab 1

        var item = new Item
        {
            Name         = name,
            Description  = description,
            CreationDate = date,
            Category     = string.IsNullOrWhiteSpace(category)
                               ? null
                               : await GetOrCreateCategoryAsync(category),
            Details      = details,                      // Navigation-Property, keine Ids
        };
        await _uow.ItemRepository.AddAsync(item);        // EIN Add: Kinder kommen mit
        await trans.CommitTransactionAsync();
    }

    private async Task<Category> GetOrCreateCategoryAsync(string name)
    {
        var existing = (await _uow.CategoryRepository.GetAsync(c => c.Name == name))
                       .FirstOrDefault();
        if (existing != null) return existing;
        var category = new Category { Name = name };
        await _uow.CategoryRepository.AddAsync(category);
        return category;
    }

    public async Task ImportFolderAsync(string root)    // alle Dateien eines Ordnerbaums
    {
        foreach (var dir in Directory.GetDirectories(root))
            foreach (var file in Directory.GetFiles(dir, "*.txt"))
            {
                var name  = Path.GetFileNameWithoutExtension(file);
                var parts = name.Split('_');
                var date  = parts.Length > 1
                            && DateOnly.TryParseExact(parts[^1], "yyyyMMdd",
                                   CultureInfo.InvariantCulture, DateTimeStyles.None, out var d)
                    ? d : DateOnly.FromDateTime(DateTime.Today);
                await ImportItemAsync(name, Path.GetRelativePath(root, file),
                                      Path.GetFileName(dir), date, file);
            }
    }
}

* Entity-Listen initialisieren: `public List<Detail> Details { get; set; } = new();`

    Result = "";
    try
    {
        var files = await Task.Run(() =>                 // CPU/Dateisystem im Hintergrund
            Directory.GetFiles(Folder!, Mask ?? "*.*", SearchOption.AllDirectories));
        var sb = new StringBuilder();
        foreach (var file in files)
        {
            var lines = await File.ReadAllLinesAsync(file);   // I/O ist schon async
            for (int i = 0; i < lines.Length; i++)
                if (lines[i].Contains(SearchText!, StringComparison.OrdinalIgnoreCase))
                    sb.AppendLine($"{file}:{i + 1}: {lines[i]}");
        }
        Result = sb.ToString();                          // nach await wieder im UI-Thread
    }
    catch (Exception ex) { Result = ex.Message; }
    finally
    {
        IsBusy = false;
        CommandManager.InvalidateRequerySuggested();     // Button wieder aktivieren
    }
}

* Takt im UI-Thread: `var t = new DispatcherTimer { Interval = TimeSpan.FromSeconds(1) };`

=== UserControl mit DependencyProperty: Linien skaliert zeichnen

[source,csharp]
----
public record Segment(Point From, Point To, Brush? Brush);   // Brush null = nicht zeichnen

// Wpf/Controls/PreviewControl.xaml(.cs): Hinzufügen → Benutzersteuerelement (UserControl)
public partial class PreviewControl : UserControl
{
    public static readonly DependencyProperty SegmentsProperty = DependencyProperty.Register(
        nameof(Segments), typeof(IList<Segment>), typeof(PreviewControl),
        new FrameworkPropertyMetadata(null, FrameworkPropertyMetadataOptions.AffectsRender));

    public IList<Segment>? Segments                      // bindbar
    {
        get => (IList<Segment>?)GetValue(SegmentsProperty);
        set => SetValue(SegmentsProperty, value);
    }

    public PreviewControl() => InitializeComponent();

    protected override void OnRender(DrawingContext dc)
    {
        base.OnRender(dc);
        dc.DrawRectangle(Brushes.White, null, new Rect(0, 0, ActualWidth, ActualHeight));
        if (Segments == null || Segments.Count == 0) return;

        // 1. Bounding Box der Rohkoordinaten
        var pts = Segments.SelectMany(s => new[] { s.From, s.To }).ToList();
        double minX = pts.Min(p => p.X), maxX = pts.Max(p => p.X);
        double minY = pts.Min(p => p.Y), maxY = pts.Max(p => p.Y);

        // 2. Faktor: Math.Min → Seitenverhältnis bleibt, Max(...,1) → keine Division durch 0
        const double m = 10;                             // Rand
        double scale = Math.Min((ActualWidth  - 2 * m) / Math.Max(maxX - minX, 1),
                                (ActualHeight - 2 * m) / Math.Max(maxY - minY, 1));
        Point ToScreen(Point p) => new((p.X - minX) * scale + m, (p.Y - minY) * scale + m);

        // 3. zeichnen
        foreach (var s in Segments.Where(s => s.Brush != null))
            dc.DrawLine(new Pen(s.Brush, 1), ToScreen(s.From), ToScreen(s.To));
    }
}
----

[source,xml]
----
<Window ... xmlns:controls="clr-namespace:Wpf.Controls">

    <controls:PreviewControl Segments="{Binding Segments}"/>
</Border>
----

* Normale C#-Properties sind *nicht* bindbar → `DependencyProperty` (Muster oben). `AffectsRender`: neuer Wert → `OnRender`,
  bei Fenster-Größenänderung wird ebenfalls neu gezeichnet. Typ der Property = was das ViewModel liefert.
* Zeichnen: `DrawLine(pen, p1, p2)`, `DrawRectangle(brush, pen, rect)`, `DrawEllipse(brush, pen, center, rx, ry)`.
  `Pen` = Linie (Farbe + Dicke), `Brush` = Füllung. Y wächst nach *unten*.
* Im ViewModel die `Segments` als `List<Segment>` berechnen und *neu zuweisen* (nicht nur ändern), damit neu gezeichnet wird.

[[fehler]]
== Häufige Fehler

* *UI aktualisiert nicht* → `SetProperty`/`OnPropertyChanged` fehlt, `List<T>` statt `ObservableCollection<T>`,
  berechnete Property nicht mitgemeldet, Array statt `ObservableCollection` beim Index-Binding.
* *Button bleibt grau beim Tippen* → `UpdateSourceTrigger=PropertyChanged` fehlt und/oder `CanExecuteChanged` nicht an
  `CommandManager.RequerySuggested` weitergeleitet. Nach async-Änderung: `CommandManager.InvalidateRequerySuggested()`.
* *Command im Template feuert nicht* → `RelativeSource AncestorType=Window` + `DataContext.XxxCommand`.
* *Trigger wirkt nicht* → Property lokal am Element gesetzt. Standardwert in den Style verschieben.
* *ComboBox zeigt Auswahl nicht* → andere Instanz als in `ItemsSource`, per Id suchen.
* *Liste doppelt* → `Clear()` vor dem Befüllen. *DataGrid doppelte Spalten* → `AutoGenerateColumns="False"`.
* *Liste scrollt nicht* → steckt in einem `StackPanel`. In eine `+*+`-Zeile legen.
* *Exception bei `GetRequiredService`* → Fenster/Service nicht in `App.xaml.cs` registriert.
* *Datei nicht gefunden* → `CopyToOutputDirectory` fehlt oder Pfad nicht über `AppContext.BaseDirectory`.
* *Designer: „existiert nicht im Namespace“* → Projekt bauen (Strg+Umschalt+B), C#-Fehler beheben, Groß-/Kleinschreibung im `xmlns` prüfen.
* *`XamlParseException` in `InitializeComponent`* → Inner Exception lesen: `Command="Binding X"` ohne `{}`,
  ungültiger Wert (`Margin="5;0"`), Bild nicht als *Resource* im Projekt, Ressource nach ihrer Verwendung definiert.
* *Test kompiliert nicht* → Name/Sichtbarkeit weicht vom Test ab. Namen aus dem Test übernehmen, `public` machen.
* *„changes … from a thread different from the Dispatcher thread“* → Collection in `Task.Run` geändert. Erst nach `await` zuweisen.
